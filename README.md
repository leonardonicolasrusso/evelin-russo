# Evelin Russo — Landing

Sitio estático (HTML + CSS + JS, sin build). Se publica en Vercel.

- `index.html` — la página. Datos editables en el bloque `CONFIG` al inicio del `<script>`:
  - `SONG_TITLE`: nombre de la canción del reproductor
  - `WHATSAPP`: número para consultas (ej. `5493415551234`). Vacío = la consulta se envía por Instagram.
- `assets/` — fotos, logo, audio (`single.mp3`) y video en vivo (`en-vivo.mp4`).
